# Проекты

Репозиторий для разных проектов. Каждый проект находится в своей папке.

## Список проектов

| Проект | Папка | Описание |
|--------|-------|----------|
| **Кел-Кел** | [`kel-kel/`](./kel-kel) | Мобильное приложение на Flutter для изучения кыргызского языка (интерфейс для русскоговорящих) |

## Как добавить новый проект

Создайте новую папку в корне репозитория и поместите проект в неё, например:

```
/
├── kel-kel/          # приложение для изучения языка (Flutter)
├── мой-новый-проект/ # следующий проект
└── README.md
```

Так все проекты живут в одном репозитории, но не мешают друг другу.
