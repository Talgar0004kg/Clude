# 💬 ChatBiz — AI-боты для бизнеса

SaaS-платформа: каждый бизнес получает **AI-бота**, который общается с
клиентами на сайте по уникальной ссылке, консультирует и собирает заявки.
Заявки приходят в кабинет и в **WhatsApp**.

> Полное описание идеи и архитектуры — в [`../PLAN.md`](../PLAN.md).

## 📁 Структура
```
ai-chat-platform/
  frontend/   — React + Vite (деплой на GitHub Pages)
  backend/    — Node + Express + SQLite + DeepSeek + whatsapp-web.js
```

## 🎨 Фронтенд (GitHub Pages)
```bash
cd frontend
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```
Работает в двух режимах:
- **ДЕМО** (по умолчанию) — данные в браузере, бот-симуляция. Можно выложить
  на GitHub Pages автономно.
- **С бэкендом** — задайте `VITE_API_URL` перед сборкой.

## ⚙️ Бэкенд
См. [`backend/README.md`](backend/README.md). Отдаётся отдельным ZIP-файлом,
запускается на постоянно работающем сервере (Railway / Render / VPS), потому
что whatsapp-web.js требует живой сессии браузера.

## 🗺️ Что реализовано
- 🏠 Лендинг (двуязычный: рус/кыргыз)
- 💬 Чат-страница клиента по ссылке + сбор анкеты
- 🤖 Настройка бота → MD-«мозг» → DeepSeek
- 📥 Заявки (мини-CRM со статусами)
- 💬 История переписок
- 📊 Статистика (посещения, переписки, заявки, конверсия)
- 🛡️ Админ-панель с модерацией ботов
- 📲 WhatsApp-уведомления о заявках
