# Кел-Кел — изучение кыргызского языка

Мобильное приложение на **Flutter** для русскоговорящих, которые хотят выучить
кыргызский язык. Интерфейс на кыргызском с подсказками на русском, слова даются
парами «кыргызский — русский».

> Сейчас реализована только **фронтенд-часть** (без бэкенда). Вход/регистрация
> работают в демо-режиме, прогресс сохраняется локально на устройстве.

## Возможности

- 🟢 **Стартовый экран** с брендингом «Кел-Кел»
- 🔐 **Вход и регистрация** (демо, локальное хранение)
- 🏠 **Главная** — дневная цель, список уроков, задание дня
- 📚 **Уроки** (`Сабактар`) — 7 тем: приветствия, семья, числа, цвета, фрукты,
  животные, мой день. Уроки открываются последовательно.
- 📝 **Детали урока** — список слов с озвучиванием
- 🎯 **Практика** (`Практика`) в 4 режимах:
  - `Сөздөр` — карточки слов
  - `Угуу` — аудирование (выбор перевода на слух)
  - `Жазуу` — письмо (написать слово по-кыргызски)
  - `Тест` — проверка знаний
- 👤 **Профиль** — статистика (изученные слова, серия дней, прогресс)
- 🏆 **Достижения** (`Жетишкендиктер`)
- 📊 **Статистика** обучения
- 🔊 Озвучивание слов через системный синтезатор речи (TTS)

## Стек

- Flutter / Dart
- `provider` — управление состоянием
- `shared_preferences` — локальное сохранение прогресса
- `flutter_tts` — озвучивание слов

## Структура проекта

```
lib/
├── main.dart                 # точка входа
├── theme.dart                # цвета и оформление
├── models/lesson.dart        # модели урока и слова
├── data/lessons_data.dart    # содержимое уроков (словарь)
├── state/app_state.dart      # глобальное состояние и прогресс
├── services/speech.dart      # озвучивание (TTS)
├── widgets/                  # переиспользуемые виджеты
└── screens/                  # экраны приложения
    ├── welcome / login / register
    ├── main_shell            # нижняя навигация
    ├── home / lessons / lesson_detail
    ├── practice/             # words / listening / writing / test
    ├── profile / stats / achievements
```
