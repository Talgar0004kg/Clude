# Telegram Agent — локальный кодинг-агент (Ollama)

Телеграм-бот, который работает как автономный **кодинг-агент** на **локальной**
модели через **Ollama** (без облака и без API-ключей). Пишете задачу в чат — бот
сам исследует файлы, вносит изменения и выполняет команды в персональной рабочей
папке, присылая каждый шаг обратно.

```
Telegram ──► бот (python-telegram-bot) ──► Ollama (localhost:11434)
                  │
                  ▼
        инструменты в рабочей папке (песочница)
   list_files · read_file · write_file · run_command · web_search · …
```

> Для каждого чата создаётся **отдельная** папка `workspace/<chat_id>` — модель
> сама решает, какие инструменты вызвать, и не выходит за её пределы.

## Установка Ollama и модели (один раз)

В Codespaces / на машине, где запускается бот:

```bash
# установить Ollama
curl -fsSL https://ollama.com/install.sh | sh

# в отдельной вкладке терминала — запустить сервер
ollama serve

# скачать модель (в ещё одной вкладке)
ollama pull llama3.2:3b
```

## Запуск бота

```bash
cd telegram-agent
pip install -r requirements.txt
cp .env.example .env        # впишите TELEGRAM_BOT_TOKEN и свой Telegram ID
python bot.py               # или ./run.sh
```
Затем откройте бота в Телеграме и напишите `/start`. Бот обращается к
`http://localhost:11434/api/chat`; если сервер не запущен — подскажет это в чате.

## Скиллы (качество работы)

В папке `skills/` лежат markdown-файлы с экспертными правилами — они
автоматически подмешиваются в системный промпт и повышают качество без правки
кода (`web_quality.md`, `landing.md`, `portfolio.md`, …). Добавить свой — положите
новый `.md` в `skills/` и перезапустите бота.

## Структура

```
telegram-agent/
├── bot.py        # телеграм-бот, стрим шагов агента в чат
├── agent.py      # цикл агента (вызов инструментов) + загрузка скиллов
├── llm.py        # клиент локальной модели (Ollama)
├── tool_specs.py # описания инструментов
├── tools.py      # инструменты: файлы, команды, веб, песочница на чат
├── config.py     # настройки из .env
├── skills/       # md-скиллы, повышающие качество
├── requirements.txt
├── Dockerfile · docker-compose.yml · run.sh
└── .devcontainer/  # для GitHub Codespaces
```

## Команды бота

| Команда | Действие |
|---------|----------|
| `/start` | приветствие |
| `/help` | примеры задач |
| `/zip` | прислать рабочую папку архивом `site.zip` |
| `/commit [сообщение]` | закоммитить код в репозиторий и запушить |
| `/model [модель]` | показать/сменить локальную модель (напр. `/model qwen2.5:7b`) |
| `/reset` | очистить контекст диалога |
| любой текст | задача для агента |
| 📷 картинка | пришлите дизайн/скриншот — свёрстает сайт **один в один** |

Агент также умеет **заходить на сайты, анализировать и скачивать** их
(`fetch_url`, `download_site`) и **искать/присылать файлы** любого типа
(`web_search`, `download_file`, `send_file`) — «найди фото кота и пришли»,
«скачай книгу в pdf». Лимит размера файла — ~45 МБ (`AGENT_MAX_DOWNLOAD_MB`).

## Переменные окружения (`.env`)

| Переменная | Обязательно | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ | Токен от @BotFather |
| `ALLOWED_USER_IDS` | ⚠️ рекомендуется | Ваш Telegram ID (у @userinfobot). Несколько — через запятую. Пусто = все |
| `OLLAMA_HOST` | нет | Адрес Ollama (по умолчанию `http://localhost:11434`) |
| `OLLAMA_MODEL` | нет | Локальная модель (по умолчанию `llama3.2:3b`) |
| `AGENT_WORKSPACE` | нет | Базовая рабочая папка (по умолчанию `./workspace`) |
| `AGENT_COMMAND_TIMEOUT` | нет | Таймаут команды, сек (по умолчанию `120`) |
| `AGENT_MAX_STEPS` | нет | Лимит шагов агента на задачу (по умолчанию `25`) |

> Модель `llama3.2:3b` — маленькая и быстрая, но для вёрстки и надёжной работы с
> инструментами лучше модель покрупнее: `ollama pull qwen2.5:7b`, затем
> `/model qwen2.5:7b` в чате (или `OLLAMA_MODEL=qwen2.5:7b` в `.env`).

## ⚠️ Безопасность

- Бот **выполняет команды** (в песочнице рабочей папки). Обязательно заполните
  `ALLOWED_USER_IDS`, иначе бот ответит любому.
- Запускайте в изолированной среде (контейнер/Codespaces).
- **Никогда не коммитьте `.env`** — он в `.gitignore`.
- Если токен засветился — перевыпустите: `/revoke` у @BotFather.
