# Telegram Agent — кодинг-агент на Gemini

Телеграм-бот, который работает как автономный **кодинг-агент** на **Google
Gemini**. Пишете задачу в чат — бот исследует файлы, вносит изменения и
выполняет команды в персональной рабочей папке, а шаги присылает обратно в чат.

```
Telegram ──► бот (Python) ──► Gemini API
                  │
                  ▼
        инструменты в рабочей папке
   list_files · read_file · write_file · run_command
```

> Для каждого чата создаётся **отдельная** рабочая папка (`workspace/<chat_id>`),
> так пользователи не мешают друг другу.

## Что нужно

- **Токен бота** от [@BotFather](https://t.me/BotFather)
- **Ключ Gemini API** — https://aistudio.google.com/app/apikey
- Ваш **Telegram ID** (узнать у [@userinfobot](https://t.me/userinfobot)) — для
  белого списка

## Быстрый старт

```bash
cd telegram-agent
pip install -r requirements.txt
cp .env.example .env
# впишите в .env: TELEGRAM_BOT_TOKEN, GEMINI_API_KEY, ALLOWED_USER_IDS
python bot.py
```
Откройте своего бота в Телеграме и напишите `/start`.

## Команды бота

| Команда | Действие |
|---------|----------|
| `/start` | приветствие |
| `/help` | примеры задач |
| `/reset` | очистить контекст диалога |
| любой текст | задача для агента |

## Настройки (`.env`)

| Переменная | Назначение | По умолчанию |
|------------|------------|--------------|
| `TELEGRAM_BOT_TOKEN` | токен бота (обязательно) | — |
| `ALLOWED_USER_IDS` | разрешённые ID через запятую | пусто = все ⚠️ |
| `GEMINI_API_KEY` | ключ Gemini (обязательно) | — |
| `AGENT_MODEL` | модель Gemini | `gemini-2.5-flash` |
| `AGENT_WORKSPACE` | базовая рабочая папка | `./workspace` |
| `AGENT_COMMAND_TIMEOUT` | таймаут команды, сек | `120` |
| `AGENT_MAX_STEPS` | лимит шагов на задачу | `25` |

## ⚠️ Безопасность

Бот **выполняет произвольные команды**. Обязательно:
- Заполните `ALLOWED_USER_IDS` — иначе любой, кто найдёт бота, сможет запускать
  код на вашем сервере.
- Запускайте в изолированной среде (контейнер/VM/Codespaces), а не на машине с
  важными данными.
- Никогда не коммитьте `.env` с токеном и ключом (он уже в `.gitignore`).

## Запуск в фоне (опционально)

```bash
nohup python bot.py > bot.log 2>&1 &
```
Для продакшена удобнее обернуть в systemd-сервис или Docker.
