# Скиллы агента

Каждый файл `*.md` в этой папке — «скилл»: набор экспертных правил, которые
автоматически подмешиваются в системный промпт агента при старте. Так можно
повышать качество работы без изменения кода.

## Как добавить свой скилл
1. Создайте файл, например `skills/seo.md` или `skills/python_style.md`.
2. Опишите в нём чёткие, конкретные правила (чем конкретнее — тем лучше).
3. Перезапустите бота (`python bot.py`) — скилл подхватится автоматически.
