# Скилл: продающий лендинг

Структура секций (сверху вниз):
1. **Шапка**: логотип слева, навигация, кнопка CTA справа. Sticky при скролле.
2. **Hero**: крупный заголовок-оффер (что и для кого), подзаголовок, 1–2 кнопки
   (основная + второстепенная), фоновое изображение/градиент. Высота ~90vh.
3. **Выгоды/фичи**: 3–4 карточки с иконкой, заголовком и описанием (Grid).
4. **Как работает**: 3 шага с нумерацией.
5. **Соц. доказательство**: отзывы (карточки с именем/аватаром), логотипы клиентов,
   цифры-достижения.
6. **Тарифы** (если уместно): 3 карточки, средняя — выделена «популярный».
7. **FAQ**: аккордеон на 4–6 вопросов.
8. **Финальный CTA**: яркая секция с призывом и кнопкой.
9. **Футер**: контакты, ссылки, соцсети, копирайт.

Принципы:
- Один чёткий призыв к действию, повторяется 2–3 раза.
- Текст по выгодам клиента, а не по фичам. Заголовки короткие и конкретные.
- Контрастные кнопки, много воздуха, читаемая иерархия.
- Плавная прокрутка к секциям по клику на навигацию.
