# Скилл: качественная вёрстка сайтов

Применяй эти правила КАЖДЫЙ раз, когда создаёшь сайт или лендинг. Цель —
современный, аккуратный, адаптивный сайт, а не «сырой» HTML.

## Структура и HTML
- Валидный HTML5: `<!DOCTYPE html>`, `<html lang="ru">`, `<meta charset="utf-8">`,
  `<meta name="viewport" content="width=device-width, initial-scale=1">`.
- Семантические теги: `<header> <nav> <main> <section> <footer>`, заголовки по
  иерархии (один `<h1>` на страницу).
- Мета для SEO/шеринга: `<title>`, `<meta name="description">`, Open Graph
  (`og:title`, `og:description`).
- Эмодзи-фавикон через `<link rel="icon" href="data:..."> `, если нет картинки.

## CSS (современный и адаптивный)
- Подключай отдельный `style.css`, не пиши стили инлайн.
- В начале — лёгкий сброс: `*{box-sizing:border-box;margin:0;padding:0}` и
  плавный скролл `html{scroll-behavior:smooth}`.
- Используй CSS-переменные для палитры и отступов:
  `:root{--brand:#...;--bg:#...;--text:#...;--radius:14px;--max:1100px}`.
- Контейнер по центру: `max-width:var(--max); margin-inline:auto; padding:0 20px`.
- Раскладки на **Flexbox/Grid**, никаких float и таблиц для вёрстки.
- Адаптивность обязательна: проверь 360px, 768px, 1200px. Используй
  `clamp()` для шрифтов (`font-size:clamp(1.8rem,5vw,3rem)`) и медиазапросы.
- Современный вид: мягкие тени, скруглённые углы, аккуратные отступы (8/16/24/48),
  hover-переходы (`transition:.2s`), системный шрифт или Google Fonts.
- Доступный контраст текста и фона; кнопки и ссылки с понятным hover/focus.

## Дизайн-ориентиры
- Сбалансированная палитра: 1 основной цвет, 1 акцент, нейтральные оттенки.
- Воздух между блоками (вертикальные отступы секций 48–96px).
- Кнопки: заметные, со скруглением и hover-эффектом.
- Картинки: `max-width:100%; height:auto; display:block`; ленивые `loading="lazy"`.
- Hero-секция с понятным заголовком и кнопкой призыва к действию.

## Доступность (a11y)
- Альты у картинок (`alt`), `aria-label` у иконочных кнопок.
- Видимый фокус для клавиатуры, логичный порядок заголовков.
- Не передавай смысл только цветом.

## JS
- Только если нужно (мобильное меню, плавный скролл, простые анимации).
- Без тяжёлых библиотек, чистый ванильный JS, подключай `script.js` с `defer`.
- Не оставляй ошибок в консоли.

## Чек-лист перед завершением
1. Открывается без внешних обязательных зависимостей (или CDN рабочие).
2. Адаптивно на телефоне и десктопе.
3. Есть `<title>`, `viewport`, фавикон, описание.
4. Кнопки/ссылки имеют hover, текст читаемый, контраст ок.
5. Нет битых путей к css/js/картинкам.
